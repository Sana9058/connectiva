# Connectiva

Connectiva is a real-time WebRTC video conferencing platform.

## Core Architecture

- React + Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- WebRTC P2P
- STUN + TURN
- JWT Authentication
- bcrypt

## Initial Meeting Capacity

Connectiva's initial WebRTC architecture is designed for small meetings of 2–4 participants.

## Development Strategy

The application will be completed and tested first.

Docker, CI/CD, and cloud deployment will be implemented only after the application is fully functional.
